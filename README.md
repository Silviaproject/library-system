# Library System

## Description

Simple Library Information System

## Requirements

- PHP
- Composer
- MySQL
- Laravel

## Installation

1. Clone repository
2. Masuk ke folder project
3. Install dependency menggunakan Composer
4. Konfigurasi database pada file `.env`
5. Jalankan database migration dengan perintah:
   `php artisan migrate`
6. Jalankan aplikasi Laravel dengan perintah:
   `php artisan serve`
7. Buka aplikasi melalui browser pada:
   `http://127.0.0.1:8000`
